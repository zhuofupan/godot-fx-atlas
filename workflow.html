① 效果合同 = 风格契约

在检索或生成前写清，缺合同就先补合同——不用「更多粒子、更亮、更炫」代替设计。以下是可直接抄进项目文档的量化基准起点（按项目调校后冻结）：

色板≤ 5 色（主色 + 邻近色 + 1 个高对比点缀）光效颜色从主体贴图/图标派生，不另起色相

② 六阶段时间轴：配比是起点，不是法律

打击类技能的节拍从这套配比起步，再按手感微调。两个硬规则：IMPACT 必须对齐游戏逻辑的命中帧（伤害判定生效的那一帧，允许 ±2 帧内微调）；telegraph 预警类把 ANTICIPATE 反转拉到 50–60%，给玩家留反应窗口。

阶段占比要点
ANTICIPATE 预备25–40%回拉/蓄势/收光；低频剪影先动，唯一的加速曲线从这里起
CAST 释放8–15%EXPO/QUINT 急缓出峰；只做一件主运动
IMPACT 命中≤ 10%对齐伤害判定帧；信息量最大的一帧：白热核 + 单帧帧闪 ≤ 1 次
RECOVER 余韵25–38%消散边界、残留、烟尘沉降；整体透明度只管总包络
CLEANUP 视觉回收10–20%缓退到不可见，禁止 alpha 突变
CLEANUP 资源回收即刻与视觉回收解耦：视觉缓退、节点立刻归还对象池，复位状态待复用
可打断是硬需求：任意阶段都要能 cancel-to-recover（直接跳余韵缓退），Tween 必须可 kill、粒子必须可停发。不能被打断的特效不是战斗特效。

③ 三类视觉层 × 性能预算

每层只管一件事；预算按最坏叠加情形计数。形状层缺失时不要用发光层硬凑——发光没有剪影可发。

层职责典型实现预算要点
shape 形状低频剪影、尺度、方向序列帧 / 贴图主体 / Line2D 刃光关闭 Glow 后仍可读出形状与方向
energy 能量发光、流动、溶解、边缘CanvasItem Shader（同形 ADD / 噪声溶解 / 极坐标）片元采样 ≤ 6 次；加法渐变必须加抖动去色带
finish 收尾余韵、残留、屏震、色差粒子 / Tween / 后处理粒子只做少量方向性余韵；屏幕层效果全屏独占、逐帧重估

⑤ 质量与合规门禁

Gallery 全绿只是入场券。接入项目前把两组清单过完，任何一项不过就打回。

  • 0.25× 慢放：逐段检查层次出入、边界溶解、注意力交接
  • 剪影测试：关闭 Glow / 去色后仍能读出形状、方向、阶段
  • 边缘视野：60° 斜角与拉远镜头下主体不糊、锚点不漂
  • 循环接缝：循环类看最后一帧 → 第一帧的轮廓与亮度连续
  • 取消与目标消失：任意阶段 cancel、目标提前死亡，均无残留或鬼影
  • 多实例压力：最坏叠加情形（多目标同帧命中）帧率达标
  • 光敏合规：全屏闪 ≤ 3 次/秒，单次亮闪 < 0.3s，避开 10–20Hz 高对比条纹
  • 纯白面积：命中白闪不做全屏纯白；用色温偏移替代亮度硬冲
  • 减闪开关：接入项目时提供「减弱闪光」辅助选项的降级路径
  • 渲染器回退：Compatibility 受限特性必须有显式降级实现
  • 资源回收：对象池复位验证——复用第 N 次与第一次画面一致
  • 预算对账：交付物附最坏情形的粒子数 / 采样数 / 帧耗时记录

⑥ 生命周期骨架 v2：命中帧对齐 + 可打断 + 对象池

把上面所有约束折进一个可直接抄的控制器。与站点首页旧骨架的区别：阶段配比参数化、支持 cancel-to-recover、池化复位、命中帧窗口断言。

extends Node2D
## fx_controller v2 — 阶段配比 / 命中帧对齐 / 可打断 / 对象池友好
## Renderer: 全渲染器可用（本骨架不依赖 SCREEN_TEXTURE / 自定义粒子 shader）

signal finished

enum Phase { ANTICIPATE, CAST, IMPACT, RECOVER, CLEANUP_VISUAL, DONE }

# 六阶段配比（合计 1.0）——按项目手感调校后冻结进常量
const STAGE_RATIO := { Phase.ANTICIPATE: 0.32, Phase.CAST: 0.08, Phase.IMPACT: 0.06,
		Phase.RECOVER: 0.38, Phase.CLEANUP_VISUAL: 0.16 }
const TOTAL_DURATION := 0.35      # 打击类基准 0.20–0.45s
const IMPACT_FRAME_TOLERANCE := 2 # 命中帧对齐容差（帧）

var _phase: Phase = Phase.DONE
var _elapsed := 0.0
var _cancelled := false
var _tweens: Array[Tween] = []     # 全部动画登记在册，cancel 时统一 kill

## 由对象池调用：复位到与首次创建一致的状态（第 N 次复用 = 第一次画面）
func reset_for_pool() -> void:
	_cancel_all_tweens()
	_elapsed = 0.0
	_cancelled = false
	_phase = Phase.DONE
	# ... 子节点视觉状态复位（alpha/scale/emitting 等）

func play_fx(impact_frame: int = -1) -> void:
	reset_for_pool()
	_phase = Phase.ANTICIPATE
	# impact_frame >= 0 时：把 IMPACT 段中心对齐到该游戏帧（±容差内微调总时长）
	# var target_t := float(impact_frame) / Engine.get_frames_per_second()
	# ... 调 TOTAL_DURATION 使 ANTICIPATE+CAST 结束点落在 target_t ± 容差

func cancel_to_recover() -> void:
	## 战斗可打断：任意阶段直接跳余韵，禁止视觉残留
	_cancelled = true
	_cancel_all_tweens()
	_phase = Phase.CLEANUP_VISUAL
	_fade_out_fast()

func _process(delta: float) -> void:
	if _phase == Phase.DONE:
		return
	_elapsed += delta
	# ...按 STAGE_RATIO 推进阶段；IMPACT 进入即触发结算表现（伤害由游戏层判定）
	if _elapsed >= TOTAL_DURATION or (_cancelled and _phase == Phase.CLEANUP_VISUAL):
		_phase = Phase.DONE
		finished.emit()   # 视觉缓退完成 → 节点归还对象池

func _cancel_all_tweens() -> void:
	for t in _tweens:
		if t and t.is_valid():
			t.kill()
	_tweens.clear()
